# PERI CLINIC — новая версия сайта

Статическая первая версия главной страницы, не зависящая от Wix.

## Запуск

Откройте `index.html` в браузере или раздайте папку любым веб-сервером. Например:

```bash
cd /root/peri-clinnic.ru
python3 -m http.server 8080
```

## Материалы для замены

Поместите исходное главное фото из Wix в `assets/hero-peri.jpg`. Остальные оригинальные фотографии, логотипы и изображения работ будут добавляться при постраничном переносе.

## До публикации

Тестовая форма сейчас не отправляет данные: требуется выбрать российский сервис записи или подключить серверный обработчик. Также будут нужны реальные ссылки на юридические документы, социальные сети, счётчики аналитики и окончательные SEO-адреса.
