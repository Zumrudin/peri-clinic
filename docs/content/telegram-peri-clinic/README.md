## Объём и полнота

Пройдены 82 страницы публичного архива до отсутствия ссылки на более раннюю страницу. Найдено **862 публикации/группы альбомов**, от 2017-12-17 до 2026-09-05. Это доступная на дату сбора история, а не число всех когда-либо отправленных сообщений: удалённые записи, комментарии и закрытые материалы не доступны. Альбом учитывается как одна публикация.

С текущим опубликованным каталогом сайта сопоставлена **21 услуга**. По ключевым словам в подписях и OCR найдено **499 постов-кандидатов**. Один пост может относиться к нескольким услугам; в число кандидатов входят общие подборки, акции и косвенные упоминания. Они собраны для полноты, но не все использованы как фактическая основа. В описаниях 100 ссылок на выбранные публикации.

Загружено **977 фотографий, 609 видеофайлов и 666 видеопревью** — всего 2252 файлов, около 2.35 ГиБ. Повторные HTML-вставки одного файла внутри поста исключены из загрузки; один и тот же материал в разных публикациях может сохраняться повторно. Это веб-версии файлов, доступные Telegram, не гарантированно оригиналы полного разрешения.

Файлы сохранены локально в [output/telegram-peri-clinic/media](../../../output/telegram-peri-clinic/media). Каталог output исключён из Git: для переноса медиа нужно копировать эту папку отдельно вместе с документами. Ссылки CDN в реестре могут истечь; опираться на сохранённые файлы.

OCR выполнен для 1643 изображений; непустой текст получен у 1504. Машинное распознавание содержит ошибки, включая фоновые надписи. Оно служит для поиска; весь OCR не вычитан. Вручную просмотренные карточки перечислены в [reviewed-media.json](reviewed-media.json).

**Ограничение видеоматериалов:** в 76 публикациях Telegram сообщает «Media is too big» для части медиа. Для 74 из них нет ни одного доступного видеофайла; в остальных могут быть сохранены другие видео того же альбома. Подписи, ссылки и доступные превью сохранены. Речь из загруженных видео **не расшифрована**, полный покадровый анализ не выполнялся. Поэтому архив доступных файлов собран, но полнота извлечения смысла из всех видео не заявляется. Для полного текстового корпуса нужны расшифровка видео и экспорт недоступных записей из Telegram.

## Как читать черновики

Основной текст — редакторское описание для будущей страницы. Блок после разделителя содержит источники и заметки, он не предназначен для размещения в пользовательской части сайта. Общие шаги консультации и наблюдения — предлагаемая структура; детали нужно сверить с фактическим процессом клиники.

Старые цены, скидки, подарки и объявления о сотрудниках сохранены только в исходных материалах. Перечень услуг взят из CMS на дату сбора, без изменения записей. Материалы производителей использованы точечно для проверки технологии и исправления противоречий, а не для подтверждения всех рекламных заявлений.

Неустановленные курс, длительность, восстановление и противопоказания оставлены незаполненными в структурированных данных. Медицинская редактура черновиков ещё не выполнена.

## Повторный сбор

Скрипты в scripts/content:

1. collect-peri-telegram.mjs — загрузка публичных страниц; --offline — повторный разбор сохранённого HTML.
2. download-peri-telegram-media.mjs — загрузка медиа и OCR (требуются curl, tesseract с rus+eng).
3. index-peri-telegram.mjs — поиск кандидатов и подготовка файлов источников.
4. prepare-peri-service-drafts.mjs — редакторские тексты и JSON.
5. report-peri-telegram.mjs — отчёт и читаемая HTML-версия.

Исходный HTML сохранён в raw/, маршрут обхода — crawl.json, снимок каталога — site-services.json.
