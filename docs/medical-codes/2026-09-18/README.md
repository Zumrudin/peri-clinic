# Коды медицинских услуг PERI CLINIC

Дата проверки: 18.09.2026. Результат — документальное сопоставление перечня клиники с номенклатурой, с явно обозначенными неустановленными соответствиями.

**Для этой задачи нужен код медицинской услуги по приказу Минздрава № 804н, а не код МКБ-10.** МКБ описывает диагноз/состояние пациента. Нельзя вывести один обязательный диагноз из названия процедуры или препарата. В этом исследовании диагнозы пациентам не присваивались.

## Что проверено

- Актуальная база Directus: **21 опубликованная процедура и 221 строка прайса**. Снимки перечней сохранены рядом с этим документом. У двух процедур — «Маски» и «Sensitec — удаление новообразований» — строк цены нет; они рассмотрены отдельно.
- Дополнительно разобраны **15 строк из шести разделов архивного прайса от 17.04.2026**, отсутствующих в актуальном наборе: консультации косметолога и трихолога, коллагенотерапия, стимуляторы коллагена, анестезия/канюля, прокол ушей. Их актуальность не подтверждена; они не смешаны с действующим прайсом.
- Проверены **31 код и их точные нормативные названия**. В справочник также включены коды, упомянутые для объяснения различий, а не для назначения.

По 221 актуальной строке: **93 соответствуют описанному вмешательству; 79 требуют подтверждения протокола; 49 оставлены без установленного кода**. Это количество строк цены, а не количество разных медицинских услуг.

## Как читать результат

«Соответствует описанному вмешательству» — аналитическое сопоставление названия и описания клиники с существующей нормативной позицией. Это не отдельное разъяснение Минздрава о конкретном бренде аппарата. Применимость относится именно к описанному вмешательству.

«Условно» — существование кода проверено, но назначение конкретной строке не подтверждено. **Колонка основного кода оставлена пустой.** Варианты нельзя импортировать как утверждённые коды и нельзя считать перечнем одновременно оказываемых услуг.

«Код не установлен» — доступных сведений недостаточно. Это не вывод об отсутствии подходящего кода вообще или о немедицинском характере процедуры.

## Что нужно для оставшихся соответствий

1. Для RF, Pladuo, Tesla Former, Beautylizer и Sensitec: точная модель, регистрационное удостоверение и инструкция, описание выполняемого воздействия и режима, зона.
2. Для мезотерапии, биоревитализации, липолитиков, ботулинотерапии и Лонгидазы: утверждённое название вмешательства, путь/слой введения, цель и регистрационная категория вводимого материала. Это сведения для кода услуги, а не поиск «кода препарата».
3. Для PRP: описание полного протокола от взятия крови до введения аутоплазмы и используемой системы.
4. Для HELEO, ProFacial, чисток, ухода и масок: какие именно вмешательства входят в каждую строку, где фотодинамический режим и где только свет.

## Замечание для внедрения на сайт

Существующее поле `procedures.icd10` подписано «МКБ-10»; все 21 прочитанное значение пустые. Коды A/B из этого отчёта нельзя записывать туда и показывать как МКБ. Нужен отдельный атрибут «Код медицинской услуги». Для неоднородных разделов (контурная пластика/Лонгидаза, HELEO/LED и др.) соответствие должно определяться конкретным видом вмешательства в строке прайса, а не одним кодом всего раздела. Код не является атрибутом бренда материала.

Коды в CMS не записывались, сайт не изменялся. Этот результат предназначен для проверки и подготовки корректного перечня; неподтверждённые строки намеренно не заполнены.
