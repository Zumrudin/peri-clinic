# Юридический раздел — перенос 11.09.2026

Источник: https://www.peri-clinic.ru/yuridicheskaya-informaciya и связанные страницы.

Перенесены восемь страниц с сохранением исходных URL:

- `/yuridicheskaya-informaciya` — каталог документов;
- `/uridicheskaya-informaciya` — реквизиты и лицензия;
- `/normativno-parvovye-dokumenty` — перечень нормативных документов;
- `/kontakty-organov` — контролирующие органы;
- `/poryadok-oplaty` — оплата услуг;

- `/soglashenie` — отдельное согласие от 01.01.2026;
- `/polzovatelskoe-soglashenie` — пользовательское соглашение.

## Содержимое и оформление

Снимок отредактированного контента: `scripts/migrate/legal-content.json`. Сайт читает документы из Directus (`pages`, шаблон `legal`), а не из JSON. Применение снимка: `node --env-file=.env.claude scripts/migrate/06-legal.mjs --apply`; без `--apply` скрипт только показывает план. Перед записью сохраняется резервная копия затрагиваемых записей в gitignored `scripts/migrate/out/legal-backups/`.

Полные абзацы оригиналов сохранены, длинные тексты разделены на смысловые блоки с заголовками и оглавлением. Реквизиты представлены списком определений. Исправлены кавычки в названии организации, пробелы в заголовках и две очевидные опечатки в политике: домен вместо адреса электронной почты заменён на `peri.clinic@mail.ru`, указанный в том же документе. Условия оплаты, сроки согласий, даты и номера нормативных актов перенесены без изменения.

PDF лицензии сохранён локально: `public/documents/medical-license.pdf`. Источник: https://www.peri-clinic.ru/_files/ugd/aab7ce_ba900ac7e72a426c958090647d05eaf2.pdf.

У пяти названий нормативных актов на исходном сайте отсутствуют адреса ссылок (проверены исходный HTML и страница после загрузки JavaScript). Перенесён весь опубликованный перечень; отсутствующие файлы не имитируются.

Для ведомств добавлены ссылки на официальные ресурсы:

- https://mosgorzdrav.ru/ru-RU/citizens/background.html — исходная ссылка Департамента здравоохранения;
- https://www.roszdravnadzor.gov.ru/about/structure/territorial/66;
- https://77.rospotrebnadzor.ru/index.php/napravlenie/29-about/common.

Исправлена прежняя классификация `/soglashenie`: это самостоятельный документ, а не дубль `/politika`. Соответствующий редирект удалён из конфигурации nginx и карты миграции.
