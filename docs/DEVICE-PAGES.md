# Страницы аппаратных процедур

Обновлены 11 страниц категории `apparatnaya-kosmetologiya`.

- Отдельный шаблон `src/templates/DevicePage.astro`: вводный блок, фотография аппарата, навигация, описание, фотографии, этапы визита, показания/противопоказания, до/после, прайс, FAQ, итог и запись.
- Описания и этапы отредактированы в Directus; снимок правок — `scripts/migrate/device-content.json`. Цены и URL сохранены. Фотографии берутся из существующих материалов, без генерации.
- Связаны семь записей аппаратов с процедурами. Фотографии сравнений из галерей классифицированы как результаты на семи страницах; повторное применение миграции не создаёт записи с тем же файлом и процедурой.
- `CaseCard` поддерживает `preserveAspect`, чтобы сравнения показывались в исходных пропорциях без обрезки. Этот режим используется на страницах аппаратов.
- Запись открывает существующий контактный диалог с контекстом процедуры.

## Материалы, которых пока нет

В текущих материалах не обнаружены сравнения до/после для Pacer One Pro (лазерная эпиляция), ProFacial, микротоковой терапии и Sensitec. На этих страницах показано пояснение и ссылка на общую галерею. У Sensitec также нет строк прайса — используется запрос стоимости у администратора.

Для добавления результатов создайте в Directus запись `before_after_cases`, укажите процедуру, пару `before`/`after` или коллаж `combined`, проверьте материалы и опубликуйте. Для цены добавьте строки `price_items` с нужной процедурой.

## Миграция

Предварительный просмотр: `node --env-file=.env.claude scripts/migrate/07-devices.mjs`.
Применение: добавить `--apply`. Перед записью исходные записи сохраняются в игнорируемой директории `scripts/migrate/out/device-backups/`. Миграция не меняет цены, статусы процедур, показания, противопоказания и FAQ. Повторное применение перезапишет отредактированные поля текстом из снимка — не запускайте его после ручной правки этих полей без сравнения.
