# Общая настольная сетка

Блок «О клинике» использует те же `--container` и `--gutter`, что и направления. Заголовок соответствует размеру заголовка направлений. Ширина больше не зависит от высоты окна; высота естественная, чтобы сохранять удобный масштаб. Портреты ограничены 320 px по ширине, сохраняют пропорции 3:4. Изменения CSS только от 801 px.

Сборка успешна. Проверены одинаковые границы и отступы с #services на 1920×1080, 1440×900, 1366×768, 1280×720, 1024×768, 1600×600. Нет горизонтального переполнения. Мобильные изображения 375/430/800 px побайтово совпали с рабочим сайтом до публикации. Проверены семь карточек с JavaScript и без него.

Это исправление заменяет прежнее требование жёстко вписывать высоту в один экран: на низком окне используется обычная прокрутка страницы.
