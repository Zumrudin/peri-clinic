# Прозрачные портреты специалистов

У четырёх фотографий специалистов удалён фон. Цвет подложки карточек, профилей и увеличенных портретов — `#DBD6D2`, средний цвет левой полосы шириной 100 пикселей исходного фото Астемира Боташева.

Обработка: rembg `isnet-general-use`; RGB-пиксели скопированы из оригиналов без изменений, добавлена только альфа-маска. Слабая фоновая дымка удалена преобразованием `clip((alpha - 2) * 255 / 251)`. На фотографии Богатыревой дополнительно уточнены две маски просветов между руками и корпусом.

Финальные PNG сохранены в `docs/media/specialists/`. Сайт получает фотографии из Directus; эти файлы — архив обработанных оригиналов. Новые и предыдущие CMS ID записаны в `uploaded.json`. Старые файлы в CMS сохранены; обновлены только ссылки `specialists.image`.

Проверка:

- RGB всех четырёх PNG совпадает с исходными фотографиями (`validation.json`).
- Загруженные файлы CMS побайтово совпали с архивными PNG.
- Все восемь опубликованных WebP (миниатюры и полноразмерные изображения) сохраняют прозрачность.
- Браузерная проверка четырёх профилей, карточек и увеличения фото пройдена при ширинах 375, 800 и 1440 px (`checks.json`).
- При переключении на фотографии интерьеров подложка портретов сбрасывается; ошибок JavaScript нет.

Стили применены к актуальной версии `main`, сохраняя существующую вёрстку профилей и поведение карусели.
