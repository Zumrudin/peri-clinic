# Проверка формы заявки на справку — 13.09.2026

Реализация в рабочем проекте; на стенд и основной сайт не опубликована. LoyalPro и его данные не менялись.

Проверено:

- `npm run build` на Node 22.23.2: 44 страницы.
- `nginx -t -c /tmp/peri-cert-nginx.conf`: изолированный nginx на 127.0.0.1:4397 с подготовленным snippet.
- Реальный GET конфигурации через HTTPS-прокси: 200, `Cache-Control: no-store`; другой clinic slug: 404.
- `node scripts/qa/cert-request.mjs`: форма для себя/родственника, свидетельство о рождении, нормализация телефонов, согласие и обязательные поля, серверная валидация, rate limit, потеря связи, сохранение введённых данных при ошибке, защита от повторного клика, скачивание PDF, истёкшая ссылка и повтор скачивания, ошибка загрузки конфигурации и повтор загрузки.
- Скриншоты 375/800/1440: без горизонтальной прокрутки при скрытом и раскрытом блоке пациента; axe формы при раскрытом блоке: 0 serious/critical. Ошибок JavaScript нет.
- `node --check src/scripts/cert-request.js`, `git diff --check` для изменённых файлов.

Все POST и выдача PDF перехвачены Playwright. Это проверка фронтенда и контракта API, не реальная заявка и не проверка содержимого PDF рабочего сервера. В рабочую базу тестовые данные не записывались.
