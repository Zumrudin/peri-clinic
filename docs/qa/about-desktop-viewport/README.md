# Настольный блок «О клинике» в пределах окна

На экранах от 801 px высота блока равна `100svh - высота шапки`. Внутренние ряды CSS Grid распределяют оставшееся пространство между интерьерами и командой. Ширина портретов рассчитывается из высоты галереи, фото сохраняют пропорции. Максимальная ширина блока 1240 px, также ограничена высотой окна. Три имеющихся портрета видны полностью; дополнительные карточки доступны в карусели.

Настольный отступ под фиксированной шапкой использует общий селектор соседей: встроенный script между header и main больше не мешает компенсации высоты шапки. Мобильные стили не изменены.

Проверки:

- `npm run build`: успешно, 43 страницы.
- `about-desktop-viewport.mjs`: блок, подписи и нижняя строка помещаются в 1920×1080, 1440×900, 1366×768, 1280×720, 1024×768, 1600×600; нет внутреннего вертикального переполнения или горизонтального переполнения страницы.
- Проверен переход из шапки по ссылке «О клинике».
- Мобильные скриншоты 375, 430 и 800 px побайтово совпали с опубликованной версией до исправления.
- Тестовая галерея из семи специалистов: стрелки работают; без JavaScript первая и последняя карточки доступны обычной прокруткой.
- `about-clinic.mjs`: повторно проверены увеличение, клавиатура, возврат фокуса, страницы специалистов и прежняя мобильная карусель результатов.
