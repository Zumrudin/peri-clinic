# Каталоги инъекционных и эстетических услуг

Ветка `feat/services-catalog-design` создана от `main` (`bcbd1d7`).

Оформление `CategoryPage.astro` приведено к каталогу `/apparaty`: заголовок и отступы, светлые карточки с золотой рамкой, нумерация, отдельный блок названия, круглая стрелка и консультация. Для фотографий услуг используется заполнение кадра, для отсутствующих обложек — текстовая заглушка PERI CLINIC. На мобильных экранах две колонки; размер длинных названий адаптирован к ширине карточки.

Проверки 2026-09-13:

- `npm run build` под Node 22.23.2: успешно, 43 страницы.
- Playwright / Chrome: обе страницы на ширинах 320, 375, 800, 801 и 1440 px; без горизонтального переполнения страницы и карточек.
- Все 6 инъекционных и 3 эстетические услуги отображаются, ссылки соответствуют собранным страницам.
- Сохранены заголовки, SEO-описания и хлебные крошки.
- Кнопка консультации открывает диалог, Escape закрывает его.
- Фото декодируются; скриншоты при 375 и 1440 px сохранены рядом. Для снимков секции скрыты фиксированные элементы навигации.

В сборке сохраняется существующее предупреждение о пересечении маршрута категории `/apparaty` со статической страницей; приоритет у статической страницы аппаратов.
