# Главная: согласование дизайн-системы — 16 сентября 2026

Выполнен аудит `docs/design/2026-09-16-home-audit.md`, кроме изменения читаемости текста поверх фотографии hero, исключённого пользователем. Цвета, scrim, кадрирование и расположение текста hero сохранены; для H1 заменена только шкала размера, устраняющая скачок на 800/801 px.

## Изменения

- Общие правила главной в `src/styles/home.css`, изолированные от внутренних шаблонов и hero: контент до 1312 px, поля 20/32 px на мобильных/планшете, единая шкала H2 34–56 px, отступы секций 48–96 px.
- Полноширинные фоны: ivory → paper → ivory → paper → dark → ivory; общий принцип границ и отступов. У ticker обычная тонкая линия.
- Переписаны накопленные локальные CSS-переопределения home-компонентов; старый блок исключений из index.astro удалён.
- Направления: общие карточки с изображением над текстом на узких экранах; одинаковый масштаб названий, без разрывов слов. На планшете первое направление занимает строку.
- Клиника: крупные фотографии помещений, одинаковые подзаголовки галерей. Врачи: фото, имя, реальная CMS-специальность и подробная страница для каждого; удалены выборочные hardcoded-описания только двух врачей. Действия выровнены.
- Аппараты, результаты и отзывы: согласованные поверхности, радиусы, типографика, кнопки 48 px. Сетка отзывов учитывает промежуток. В мобильных отзывах добавлены стрелки; общий rail поддерживает отключение кнопок у края и клавиатуру.
- Призыв к записи: цельная композиция фото и цветовой панели без одновременного стекла, свечения и нахлёста. Один курсивный акцент сохранён здесь.
- Шапка и футер главной выровнены с контентом; контакты и ссылки футера увеличены. Cookie компактнее; нижняя панель учитывает безопасную область экрана. Основные правила внутренних страниц сохранены.
