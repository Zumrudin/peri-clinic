# Навигация по прайс-листу

Страница: `/uslugi-i-ceny`. Ветка: `feat/pricing-navigation`, основана на `main`.

## Утверждённый вариант

- На компьютере — закреплённое оглавление с категориями и вложенными процедурами.
- До 1000 px — три видимые ссылки-переключателя направлений. Отображаются процедуры выбранного направления.
- Выбранная категория: `--gold-05` (#faf7ef), текст `--gold-deep`, нижняя линия 1 px с `--line-gold`. Цвета остальной страницы сохранены.
- Якорные ссылки раскрывают прайс, переводят фокус к выбранному разделу и учитывают высоту шапки и мобильной навигации.
- Смена направления в начале страницы сохраняет позицию прокрутки; при выборе дальше по странице возвращает к началу выбранного списка.
- Категории, процедуры и цены формируются из существующего `getPriceListGrouped()`. Данные CMS и видимость цен не изменены.
- Мобильные цены используют существующий режим карточек `PriceTable`.
- Без JavaScript доступны все разделы, якорные ссылки и нативные аккордеоны.

## Проверка

```bash
npm ci --include=dev
npm run check
npm run build
python3 -m http.server 4346 --bind 127.0.0.1 --directory dist
# В другом терминале:
node scripts/qa/pricing-navigation.mjs http://127.0.0.1:4346
```

Node 22.12+; Chrome по умолчанию `/usr/bin/google-chrome`, иной путь через `CHROME_PATH`.
Зависимости `@astrojs/check` и `typescript` добавлены в devDependencies, чтобы существующая команда `npm run check` работала после чистой установки.

Сценарий проверяет 320/375/800/1440 px: переключение, историю назад/вперёд, прямой URL на процедуру другого направления, повторное раскрытие, клавиатуру, переход между мобильной и компьютерной версией, отступы от закреплённой навигации, отсутствие горизонтального переполнения и ошибок JavaScript. Axe: нет serious/critical в блоке прайса. Дополнительно проверяется доступность всех разделов без JavaScript.
