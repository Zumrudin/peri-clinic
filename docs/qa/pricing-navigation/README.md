# Навигация по прайс-листу

Страница: `/uslugi-i-ceny`. Категории и вложенные процедуры формируются из существующего `getPriceListGrouped()`, без изменения данных CMS.

- Закреплённое оглавление на десктопе; до 1000 px — три видимые ссылки-переключателя направлений в прежней молочно-золотистой палитре. Показываются процедуры выбранного направления, без JavaScript остаются доступны все разделы и якорные ссылки.
- Якорные ссылки раскрывают прайс, переводят фокус к выбранному разделу и учитывают высоту шапки/мобильного меню.
- Ссылки на отдельные процедуры работают при загрузке страницы и повторном выборе.
- Мобильные цены используют существующий режим карточек PriceTable.
- Без JavaScript остаются доступными оглавление, якорные ссылки и нативные аккордеоны.

Проверено в Chromium на 375, 800 и 1440 px: переходы, раскрытие по прямому URL после перезагрузки, отсутствие горизонтального переполнения. Axe для блока `.pricing`: 0 serious/critical. `npm run check`: 0 errors, 0 warnings (есть существующие hints).
