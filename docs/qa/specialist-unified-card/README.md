# Страница специалиста: единая карточка

Ветка: `feat/specialist-unified-card-ui`.

## Проверка

Node 22: `ABOUT_DEMO=true npm run build`, затем запустить preview и выполнить `node scripts/qa/specialist-unified-card.mjs <base-url>`.

Скрипт проверяет 320/375/800/1440 px: расположение профиля, горизонтальный ряд / карусель, индикаторы, клавиатуру, фото, запись, длинное имя и описание, отсутствие горизонтального переполнения и серьёзных ошибок axe. Видео проверяется с локально сгенерированным WebM: воспроизведение, отсутствие автозапуска, остановка и возврат фокуса при закрытии. Без JavaScript ссылки открывают оригиналы.

Проверка 2026-09-13: все сценарии скрипта прошли, результаты в `checks.json`. Сохранены скриншоты всех четырёх размеров. Проверены нормализация ссылок и совместимость пустых медиасписков.

## Заполнение CMS

Перед заполнением новых полей запустить существующую аддитивную миграцию `node directus/setup/about-schema.mjs` в целевом окружении. В рамках разработки схема живой CMS не изменяется.

В записи специалиста доступны `media_title`, `media_description` и список `media`. Каждый элемент содержит:

- `title`: название материала;
- `description`: короткая подпись;
- `image_url`: обязательная публичная ссылка на фото или обложку;
- `image_alt`: описание изображения;
- `focus_y`: положение кадра по вертикали от 0 до 100 (по умолчанию 50);
- `video_url`: необязательная прямая ссылка на MP4/WebM;
- `captions_url`: необязательная ссылка на русские субтитры WebVTT.

Адреса — HTTPS или локальные `/media/...`, доступные посетителю без авторизации. Приватные ссылки Directus с `access_token` не подходят. Для внешних субтитров сервер должен разрешать CORS; видео без субтитров не требует режима CORS. Страницы видеохостингов и iframe не поддерживаются. Порядок списка определяет порядок карточек. Пустые и незаполненные карточки не выводятся; пустой медиараздел скрывается. До миграции старые профили продолжают работать.

Демо-режим использует существующие иллюстративные портреты и интерьеры с явными подписями. Настоящих видео сотрудников в репозитории нет, поэтому имитация кнопки воспроизведения на демо-фото не добавляется. В production отображаются только материалы CMS.
