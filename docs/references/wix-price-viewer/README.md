this site (commits from 2026-02-01 to 2026-04-18): the clinic price list as JSON + PDF and the
two Velo scripts that rendered the PDF on the Wix site. Kept for reference only — the live price
list is in Directus (see `directus/setup/seed-prices.mjs`, `src/components/pricing/`); nothing
here is used by the build.
