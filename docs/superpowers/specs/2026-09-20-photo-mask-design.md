# Плашки PERI на фотографиях

В каждом одиночном поле фотографии Directus добавить редактор рядом со стандартной загрузкой/выбором файла. Редактор открывает оригинал, позволяет перемещать до 12 непрозрачных фирменных плашек, менять их ширину, высоту и угол. Pointer Events для мыши/касания, стрелки клавиатуры и подписанные настройки. На мобильном фото над настройками; на компьютере — рядом.

Используется оформление Directus (фон, текст, рамки, системный шрифт); акцент #aa892f. Сама плашка #24231f с векторной надписью PERI #d4bb83. Никаких зависимостей от внешних шрифтов и сервисов распознавания лиц.

Сервер формирует новый PNG без EXIF в исходном разрешении с учётом ориентации исходника. Плашки входят в пиксели. UUID копии поступает в редактируемое поле; публикация происходит через существующее сохранение записи и сборку сайта. Оригинал не меняется. Поле directus_files.peri_eye_edit хранит UUID оригинала и нормализованные координаты, поэтому повторное редактирование не накапливает плашки и потери качества.

Доступ к endpoint требует авторизованного пользователя с доступом в админку; FilesService/AssetsService используют accountability запроса. Оригиналы остаются в закрытой библиотеке CMS с существующими правами сотрудников и технического сборщика; публичные права не добавляются. Обработка JPEG/PNG/WebP до 50 МБ и 40 мегапикселей, только статичные изображения. Одновременно обрабатывается один запрос для ограничения расхода памяти.

## Ручная загрузка и замена фотографии, 2026-09-21

Под стандартным полем всегда доступна подписанная кнопка загрузки с устройства: для пустого поля «Загрузить фото с устройства», для заполненного — «Заменить фото с устройства». Выбор файла открывает системный диалог, загрузка проходит через авторизованный API Directus. После успеха UUID нового файла поступает в форму; запись сохраняется обычным способом. Старый файл не перезаписывается. Во время загрузки действия поля заблокированы, при ошибке текущая фотография сохраняется и доступна повторная попытка. Для недоступного для редактирования поля кнопка скрыта.
