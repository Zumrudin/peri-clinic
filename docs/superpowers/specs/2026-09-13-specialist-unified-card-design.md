# Страница специалиста — единая карточка

Утверждён первый референс: общий светлый блок с портретом, ФИО, специализацией, описанием и записью. Используем существующие токены, тонкие золотистые контуры и скругления карточек услуг. На компьютере портрет слева, текст справа; до 800 px блок становится вертикальным.

Под профилем — материалы специалиста: фото рабочего процесса, видео, события. На компьютере три карточки в ряд; дополнительные материалы переходят на следующую строку. На мобильном — горизонтальная карусель со scroll-snap, краем следующей карточки и кнопками-индикаторами. Фото открываются в диалоге, видео — в том же диалоге с нативными controls, без autoplay. Ссылки доступны без JavaScript.

CMS: необязательный упорядоченный JSON-список `media` у специалиста (заголовок, подпись, публичный URL обложки, alt, необязательные URL видео и субтитров). При отсутствии материалов раздел скрыт. Заголовок и описание раздела редактируются у специалиста. Только прямые HTTPS или локальные URL, без токенов. Новые поля вводятся существующей аддитивной миграцией `about-schema.mjs`; старые записи совместимы до миграции.

Демонстрационные материалы существуют только при ABOUT_DEMO=true, не публикуются в CMS и не индексируются. Настоящие данные не заменяются вымышленными. Изменения разрабатываются в ветке feat/specialist-unified-card-ui; публикация сайта не входит в эту работу.
