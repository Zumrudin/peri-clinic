# Форма заявки на справку

Пользователь выбрал оставить обработку заявок и создание PDF в LoyalPro. На `/spravka` размещается нативная форма в оформлении сайта вместо ссылки на внешний сервис. Существующий шаблон Directus `spravka` включает форму; заголовок и текст страницы по-прежнему редактируются в CMS. Для импортированного заголовка-заглушки `spravka` предусмотрен русский запасной заголовок.

API: `/api/public/cert-requests/clinic-1`, `/config`, `/application/<token>` на домене сайта. Nginx передаёт только эти маршруты на `https://forma.zumrudin.ru`, проверяя сертификат. Идентификатор клиники фиксирован на стороне сайта и прокси; административные маршруты и другие клиники не проксируются. LoyalPro и его база не меняются. Поле CMS `spravka_form_url` сохраняется для совместимости, новая форма его не использует.

Сохраняется контракт текущей формы: данные плательщика, отдельного пациента при необходимости, паспорт/свидетельство пациента, родство, год, согласие и honeypot. Годы и родство загружаются из API. Окончательная проверка, включая контрольные цифры ИНН, выполняется LoyalPro. Обязательность отчества соответствует действующему серверу.

Кнопка отправки недоступна до загрузки конфигурации и во время запроса. Повторная загрузка конфигурации, ошибки валидации, ограничения частоты, потеря связи и истечение PDF-ссылки имеют отдельные состояния. POST автоматически не повторяется. После подтверждённого успеха поля очищаются; токен хранится только в памяти страницы. PDF скачивается через Blob, без перехода на внешний сайт и без токена в адресе страницы. Перезагрузка страницы после успеха теряет ссылку на PDF — для нового заявления нужно обратиться в клинику, не отправлять дубль заявки.

Согласие ведёт на `/politika`. Поля не сохраняются в browser storage; форма помечена `ym-hide-content`. API-ответы не кэшируются, access log API отключён, Cookie/Authorization/Referer посетителя не пересылаются в LoyalPro. Клиентский IP заменяет входной X-Forwarded-For для действующего ограничения частоты.

Проверка: реальный GET конфигурации через отдельный локальный nginx; POST и PDF только через перехват в Playwright, без записей в рабочую базу. Сценарии: заявка для себя и родственника, ошибки, повторный клик, скачивание и истечение ссылки, экраны 375/800/1440, axe.
