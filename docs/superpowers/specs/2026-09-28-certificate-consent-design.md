# Отдельное согласие для справки

Scope: отдельное версионированное согласие, самостоятельная ссылка на политику,
дополнение политики сценарием справки, сохранение доказательства согласия в LoyalPro.
Сравнить с шаблонами medical-docs, не переносить общедоступность отзывов и бессрочность.

CMS остаётся источником текста сайта. Новый документ имеет неизменяемый slug и версию;
SHA-256 считается от title + LF + body. При изменении текста нужна новая версия.
Сервер хранит канонический текст из release snapshot вместе с заявкой, не текст клиента.
Форма проверяет совпадение версии и SHA между опубликованной страницей и API config.
Несовпадение блокирует отправку. POST требует boolean true и актуальные version/hash.
Другие салоны сохраняют прежний API; правила PERI действуют только для clinic-1.
Исторические заявки не получают выдуманную редакцию задним числом.

Согласие относится к данным заявителя; родство само по себе не даёт полномочий
согласиться за другого совершеннолетнего. Форма отдельно объясняет необходимость
правового основания, клиника проверяет полномочия до выдачи справки.
Checkbox не является усиленной электронной подписью и не заменяет письменное согласие,
если оно требуется законом. Согласие не включает рассылку, Метрику и публикацию данных.

Production deploy backend требует отдельного одобрения по /root/loyalpro/AGENTS.md.
До него: локальные изменения, тесты без реальных заявок, документы для просмотра.
