# Актуализация прайса по YCLIENTS

Источник: выгрузка от 19 сентября 2026, 290 услуг / 757 назначений сотрудников.
Снимок и построчный план: `docs/pricing/2026-09-19/`.

Directus остаётся источником контента. Услуги сопоставлены вручную по разделу,
названию, дозировке и условиям; идентификаторы dev не используются для сопоставления на prod.
Пери Гаджиева соответствует колонке главного врача. Диапазон обычных врачей
сохраняется в `price` / `price_max`; различия по сотрудникам описываются в примечании.

Услуги без страницы процедуры получают `price_group` и показываются отдельными
разделами общего прайса. Новые страницы процедур не создаются.
Старые строки без однозначного соответствия сохраняются; технические 0–1 ₽,
неоднозначные дубли и тарифы сеансов по абонементам перечисляются в отчёте отдельно.
SLIM BODY и MPX разделены: у MPX нет назначенной Пери в выгрузке.

Dev и prod используют разные базы. Для каждого нужен отдельный запуск миграции
и сборки. Изменения пока предназначены dev; публикация prod определяется ответом пользователя.

Мобильные разделы прайса прокручиваются по горизонтали: при восьми разделах
сетка занимала три строки и перекрывала якоря. Переходы повторно выравниваются
после перехода шапки в фиксированное положение.
