# Мобильный блок подарочного сертификата

После отзывов и перед заключительным обращением добавляется блок с одобренным роликом упаковки сертификата. Показ только при ширине до 800px включительно; десктоп не загружает медиа. Полный кадр 9:16 без обрезания, первый кадр без сургуча, последовательность видео сохранена.

Оформление продолжает сайт: paper #fbfaf7, ivory #f6f4ef, ink #24241f, ink-2 #56544c, gold-deep #7f651f. Cormorant Garamond для заголовка, Golos Text для описания и кнопки. Центрированный заголовок → вертикальный ролик → краткое описание → кнопка связи. Максимальная ширина содержимого 420px. Главный акцент — сам сертификат и движение, без дополнительных украшений.

Кнопка открывает существующее окно контактов с темой «Подарочный сертификат». Тексты и ссылки на видео/постер редактируются в Directus home. Отдельных обещаний о номинале, сроках и оплате нет.

Видео без звука, playsinline, preload none. Запуск в зоне видимости, пауза при выходе и скрытой вкладке, доступная кнопка управления. Reduced motion и экономия трафика отключают автоматическое воспроизведение. MP4 H.264 faststart и WebP-постер публикуются отдельно от исходника, исходник сохраняется.
