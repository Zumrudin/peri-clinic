# Анимационный рефреш сайта PERI CLINIC — аудит и дизайн-решение

Дата: 2026-09-14. Коммит на момент аудита: `d5cff2a`.
Метод: скиллы `find-animation-opportunities` и `improve-animations` (по философии Эмиля Ковальски:
анимация должна отвечать на вопрос «зачем», UI-движение короче 300 мс, сильный `ease-out`,
вход и выход симметричны, reduced-motion = «меньше и мягче», а не «ноль»).

Цель заказчика: ощущение лёгкости и плавности, «дорогой» сайт клиники косметологии.
Решение: не добавлять эффекты ради эффектов, а (1) починить существующее движение,
(2) закрыть места, где контент «телепортируется», (3) один осознанный элемент восторга на первом экране.

## Что есть сейчас

- Чистый CSS + маленькие TS-скрипты в `src/scripts/*`, без библиотек анимации.
- Токены движения: `--ease-out: cubic-bezier(0.2, 0.7, 0.2, 1)`, `--dur-fast: 0.25s`, `--dur-slow: 0.75s` (`src/styles/tokens.css:88`).
- `.reveal` (появление секций при скролле) — 0.8 с, 24px, opacity на встроенном `ease`, без стаггера (`src/styles/base.css:359`).
- Диалоги (`<dialog>`): лист записи входит через keyframes, закрывается мгновенно; лайтбокс и медиа-диалог открываются мгновенно.
- Sticky-шапка анимирует `height` и заново проигрывает слайд при каждом пересечении порога 120px.
- Reduced-motion глобально гасит все transitions до 0.01 мс, включая цветовые hover.
- Hover-движение не отгорожено от тач-устройств.

## Решение (12 планов, см. `docs/superpowers/plans/2026-09-14-animation-refresh/`)

Исправления существующего движения: 001 токены + reveal, 002 лист записи, 003 sticky-шапка,
004 мобильное меню, 005 reduced-motion, 006 hover на таче.
Новые движения: 007 аккордеоны, 008 переходы между страницами, 009 отклик на нажатие,
010 плашка cookie, 011 лайтбокс и медиа-диалог, 012 фото первого экрана.

Единая система значений:

| Назначение | Значение |
| --- | --- |
| Вход/выход, hover | `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)` |
| Движение по экрану | `--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1)` |
| Листы и шторки | `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)` |
| Нажатие | `--dur-press: 0.16s` |
| Hover, выходы диалогов, аккордеоны | `--dur-fast: 0.25s` |
| Появление секций при скролле | `--dur-reveal: 0.6s`, сдвиг 16px, стаггер 60 мс |
| Вход листа/шторки | 0.4 с на `--ease-drawer` |
| Фото первого экрана | 1.6 с, `scale(1.05)` → 1, один раз за загрузку |

Отклонено осознанно: движение в бегущей строке (уже `linear`), эффекты на пунктах меню сверх подчёркивания,
анимация фильтра результатов (45 карточек, перестройка сетки), движение в таблицах цен,
побуквенное появление заголовков, параллакс фоновых блобов, JS-пружины в каруселях.

## Порядок и приёмка

Одна ветка `feat/animation-refresh`, один коммит на план. После каждого коммита стенд
`peri.zumrudin.ru` пересобирается из ветки, заказчик визуально подтверждает, затем следующий план.
Детали в `plans/2026-09-14-animation-refresh/README.md`.
