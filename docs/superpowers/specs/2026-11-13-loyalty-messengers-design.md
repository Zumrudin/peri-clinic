# Регистрация в программе лояльности

Обе кнопки страницы /loyaltyprogram открывают компактный нативный dialog с выбором Telegram или МАКС. Ссылка Telegram сохраняется с параметром start; МАКС: https://max.ru/id695205769103_bot. На ширинах более 800 px внутри каждой ссылки показан QR-код; на мобильном остаются крупные ссылки с иконками. Закрытие крестиком, Escape или по фону; возврат фокуса на кнопку. Тексты и ссылки хранятся в body страницы Directus. Цвета и типографика соответствуют существующей странице.
