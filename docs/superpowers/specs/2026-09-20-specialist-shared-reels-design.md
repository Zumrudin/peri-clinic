# Общий плеер рилсов в профиле сотрудника

Видео профиля используют компонент и контроллер рилсов главной: встроенное воспроизведение, HLS с MP4 fallback, окно предзагрузки, звук, прогресс, скрытие подписи и переход после завершения. Главная остаётся мобильной; профиль показывает рилсы на всех ширинах. Данные берутся из материалов соответствующего сотрудника в Directus. Фото остаются в существующей галерее с увеличением. Субтитры и позиция кадра сохраняются.

Сборка создаёт производные MP4/HLS для объединения видео главной и опубликованных профилей, исключая повторное кодирование одинаковых файлов.
