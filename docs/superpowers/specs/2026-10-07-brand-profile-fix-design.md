# Единое оформление и ссылки на специалистов

Запрос: убрать двойной логотип, вернуть фон с лепестками на внутренних страницах, восстановить переходы по фото специалистов как в последнем готовом концепте.

Источник поведения: `68b7b69`, mobile v14 — у портретов обычный href профиля, без data-photo и обработчика lightbox. Сохраняем карусель; фотографии интерьеров и фото на странице специалиста по-прежнему увеличиваются.

Шапка и подвал содержат только новый SVG. Общие стили включаются в HTML через штатный inlineStylesheets, чтобы оформление не зависело от доступности CSS предыдущего релиза. Палитра и ботанический слой действуют на внутренних страницах при любой ширине; мобильная геометрия шапки остаётся в media query.

При обследовании текущая свежая мобильная загрузка уже имела фон и один видимый логотип. Причина состояния на пользовательском скриншоте не воспроизведена. Удаление второй картинки устраняет саму возможность дублирования; inline CSS исключает зависимость общего оформления от устаревшей ссылки на отдельный stylesheet.
