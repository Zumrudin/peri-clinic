## Импорт

Node 22; credentials: DIRECTUS_URL и DIRECTUS_ADMIN_TOKEN либо DIRECTUS_ADMIN_EMAIL/PASSWORD.

`node scripts/reviews/import.mjs export.json` проверяет без записи.
`node scripts/reviews/import.mjs export.json --apply` создаёт черновики.
`node --test scripts/reviews/import.test.mjs` проверяет валидацию и повторные запуски.

Формат массива: `{ "id": "постоянный ID отзыва", "author_name": "Имя", "text": "Полный текст", "rating": 5, "date": "2026-09-22", "source_url": "https://yandex.ru/maps/...прямая ссылка..." }`.
Запускать один импорт одновременно. При сбое можно повторить; успешно созданные записи пропускаются. Редактирование текста существующего отзыва на Яндексе пока не синхронизируется.

Найденные карточки (проверить перед заполнением CMS):
- https://yandex.com/maps/org/peri_clinic/38588977489/reviews/
- https://2gis.ru/moscow/firm/70000001057552313/tab/reviews

Для развёртывания сначала применить схему `node scripts/reviews/setup.mjs`, затем сборку. Не публиковать пустые кнопки или ссылки на поиск Google вместо карточки клиники.

Проверка доступа: доступный локальный токен читает CMS, но POST /fields/home возвращает 403. Миграция не применена. Поле кнопок необязательно в загрузчике, поэтому существующая CMS остаётся совместимой.

## Браузерный сбор (22 сентября)

Прямое открытие карточки через Playwright на yandex.ru и yandex.com вернуло `limited`. Публичный maps-reviews-widget доступен: получены 5 текстов с пятью заполненными звёздами. Это выборка виджета, а не все 387 отзывов, указанных в нём.

Повторный сбор: `node scripts/reviews/scrape-widget.mjs <каталог>`. Сохраняет JSON для импорта, HTML для чтения, метаданные и исходную разметку. Год даты неизвестен → date=null; дата как показана на площадке хранится в date_label выгрузки. Ссылка ведёт на организацию. ID является SHA-256 от организации, автора и текста, а не оригинальным ID Яндекса; изменение текста изменит ID. Импорт умеет сохранять разные отзывы с общей ссылкой организации. Импорт в CMS не выполнен из-за прежнего ограничения доступа к схеме.
