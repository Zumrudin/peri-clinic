# Обновление нормативных документов и ОМС

- Ссылки на программы — МГФОМС, московская карточка содержит редакцию от 28.07.2026.
- Все 6 внешних ссылок на странице проверены GET: HTTP 200.
- Добавлено уведомление в нормативный раздел и организационные документы.
- Сохранена информация о бесплатной помощи в рамках программ в участвующих организациях.
- Migration 26 применена в dev и production; исходные записи сохранены в
  scripts/migrate/out/normative-oms-backups/. Повторный запуск: Already current.
- Вёрстка и API не менялись. Штатная автоматическая сборка CMS без ручного параллельного запуска.
