# Блок «О клинике»: реализация и наполнение

Реализация подготовлена в `feat/about-clinic-gallery`. Вёрстка, карусели, страницы специалистов и подключение к Directus реализованы. 13 сентября 2026 блок опубликован на https://peri.zumrudin.ru из коммита `99ee3ab`; результаты проверки — в `docs/qa/about-clinic/README.md`.

## Контент в CMS

- **О клинике — тексты блока** (`clinic_about`): надзаголовок, заголовок, описание, заголовки галерей, кнопка «Подробнее», ссылка на документы, пометка временных материалов.
- **Фотографии клиники** (`clinic_photos`): изображение, подпись, alt, порядок, статус и флаг временного изображения.
- **Специалисты** (`specialists`): имя, специализация, slug страницы, портрет, положение кадра, описание под фото, SEO, порядок, статус и флаг демонстрационного профиля.

В CMS загружены три фотографии помещений и три портрета, вырезанные из согласованного референса. У всех записей `is_demo=true`. Страницы демонстрационных специалистов имеют noindex и исключены из sitemap. Для настоящего специалиста заменить фото и текст, задать slug, затем выключить флаг демонстрационного профиля. Черновики не выводятся на сайт.

Тексты нового блока хранятся в отдельном singleton, поэтому прежние поля главной не перезаписывались. Картинки оптимизируются при статической сборке; приватные URL CMS не попадают в браузер.

## Запуск и проверка

Требуется Node 22+. Локальный `.env`: `ABOUT_DEMO=false` — рабочая ветка читает новые коллекции из CMS. `ABOUT_DEMO=true` оставлен только для автономной демонстрации блока; остальные разделы сайта по-прежнему требуют Directus.

```sh
npm run check
npm run build
npm run preview
node scripts/qa/about-clinic.mjs http://127.0.0.1:4332
node scripts/qa/about-clinic-edge.mjs http://127.0.0.1:4332
```

В этом окружении существующий preview обслуживает `dist` на порту 4332. Фактический адрес смотреть в выводе `astro preview`.

## Повторная установка CMS на другом окружении

Скриптам необходим административный доступ через `DIRECTUS_ADMIN_TOKEN` либо `DIRECTUS_ADMIN_EMAIL`/`DIRECTUS_ADMIN_PASSWORD`.

```sh
node directus/setup/about-schema.mjs
node directus/setup/seed-about.mjs
node directus/setup/about-flows.mjs
```

Миграция добавляет коллекции, поля, отношения к файлам и права существующих редактора/Builder, не изменяет редакторские записи. Seed заполняет только пустые коллекции и пустой singleton; существующие записи не перезаписываются. Имена файлов содержат `about-reference-`, описание указывает, что изображения временные.

Последний скрипт добавляет новые коллекции в уже существующие автоматический и ручной flows публикации, сохраняя остальные настройки и статус flows. Выполнять после seed, чтобы первичное наполнение не запускало лишние сборки.

`directus/about-snapshot.json` — экспорт схемы только трёх новых коллекций для ревью. Это **не полный snapshot сервера**, его нельзя применять как замену всей схемы. Исходный полный `snapshot.yaml` оставлен без перезаписи посторонних коллекций; декларации в `collections.mjs` включают новый блок.

## Композиция и взаимодействие

На телефоне описание расположено под заголовком на всю ширину: 12 px на телефоне, 13 px на планшете. Три интерьера видны в одном ряду. На телефоне ширина портрета 35% (два полных и большая часть третьего), на планшете 601–800 px — 43%. На компьютере от 801 px весь блок занимает высоту окна за вычетом шапки; ширина портретов вычисляется из доступной высоты галереи, пропорции фотографий сохраняются. Максимальная ширина блока 1240 px. Мобильные стрелки 44 px, компактные настольные 30 px.

Клик на фото увеличивает изображение. «Подробнее» — независимая ссылка на страницу, где описание расположено под фотографией. Галереи команды и помещений не смешиваются. На странице специалиста увеличенный просмотр позволяет листать всю команду. Стрелки, клавиши и свайп работают по кругу, без автоматического перелистывания.

При закрытии увеличенного просмотра основная карусель показывает последнее выбранное фото и возвращает фокус. При одной фотографии навигация скрыта. Если все карточки помещаются в ряд, стрелки основной карусели скрыты; в увеличенном просмотре остаётся листание.
