# Блок «О клинике»: запуск и наполнение

Ветка: `feat/about-clinic-gallery`.

## Локальный просмотр

Требуется Node 22+. В `.env` включён `ABOUT_DEMO=true`. Этот явный режим использует только локальные временные профили/интерьеры, не читает новые CMS-коллекции и не записывает вымышленных сотрудников в CMS. Остальные разделы сайта по-прежнему загружаются из Directus.

```sh
npm run dev
npm run check
npm run build
npm run preview -- --port 4332
node scripts/qa/about-clinic.mjs http://127.0.0.1:4332
node scripts/qa/about-clinic-edge.mjs http://127.0.0.1:4332
```

Демонстрационные страницы закрыты от индексации и исключены из sitemap. Режим по умолчанию, без флага, требует настоящие коллекции. При 3 временных портретах видно 2 полных и часть третьего; на среднем экране ширина карточки 43%, на телефоне 35%. При большем числе сотрудников можно уменьшить ширину до 30%, чтобы помещались три и край следующего.

## CMS: требуется применение миграции

Текущий API-токен вернул 403 при создании коллекций. Миграция подготовлена, но не применена; snapshot действующей CMS не изменён.

Администратор с доступом к схеме запускает:

```sh
node directus/setup/about-schema.mjs
```

Скрипт использует `DIRECTUS_ADMIN_TOKEN` либо `DIRECTUS_ADMIN_EMAIL`/`DIRECTUS_ADMIN_PASSWORD`, добавляет `clinic_photos` и `specialists`, отношения к файлам и права существующих редактора/Builder, не перезаписывает записи. Определения также включены в общую `collections.mjs` для новых установок.

После применения проверить права реального сборщика, обновить snapshot стандартным процессом проекта. Обновить существующие flows через `directus/setup/flows.mjs`, чтобы изменения новых коллекций вызывали пересборку (они включены в `contentCollections`). Проверить публикацию одной тестовой записи перед наполнением.

В CMS заполнить описание главной (`approach_title`, `approach_lead`), фотографии клиники (файл, подпись, alt, порядок, статус), специалистов (имя, специализация, slug, портрет, положение кадра 0–100, описание под фото, SEO, порядок, статус). Выключить `ABOUT_DEMO`, пересобрать сайт. Не публиковать демонстрационные материалы как настоящие фотографии клиники.

## Временные изображения

`src/assets/about/*.webp` — вырезаны Sharp из утверждённого `output/imagegen/about-clinic/04-portrait-carousel.png` по просьбе пользователя. Источник имеет 1254×1254 px; у портретов примерно 350×494 px. Для финального увеличенного просмотра нужны оригиналы более высокого разрешения.

## Поведение

Клик на фото увеличивает изображение. «Подробнее» — независимая обычная ссылка на страницу. Галереи команды и помещений не смешиваются. На странице врача увеличенный просмотр позволяет листать всю команду. Стрелки, клавиши и свайп работают циклически; автолистания нет. При закрытии главная карусель показывает последнее выбранное фото и возвращает фокус. При одной фотографии навигация скрыта. При полностью помещающейся группе стрелки основной карусели скрыты; увеличенный просмотр по-прежнему позволяет листать.

Существующая карусель результатов не изменена. В `homeContent.ts` добавлена явная проверка обязательных изображений (hero, категория, CTA), устраняющая прежние ошибки nullable при проверке типов без изменения нормального отображения.

## Уточнение мобильного дизайна

По пожеланию пользователя мобильная композиция приближена к настольной: описание остаётся справа от заголовка, три интерьера видны в одном ряду, портреты занимают 35% ширины карусели (два полных и большая часть третьего). Уменьшены отступы и заголовки. Стрелки сохраняют размер 44 px, фото увеличиваются по нажатию; тексты и кнопки не масштабируются целиком как изображение настольной страницы. Для одной/двух карточек, помещающихся в ряд, стрелки основной карусели скрыты.
