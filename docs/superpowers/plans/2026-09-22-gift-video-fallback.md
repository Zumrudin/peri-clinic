# Исправление пустого блока сертификата

Проблема: видео и poster указывали на отдельный dev-домен; poster назначался только JavaScript при попадании видео в viewport. При блокировке воспроизведения/ошибке загрузки не было независимого статического изображения.

Изменение: выбранные в CMS файлы копируются в статическую сборку под /media/gift/ с хешем содержимого. Самостоятельный lazy img присутствует в HTML, видео становится видимым только после playing. При error/emptied снова видна обложка. Перед воспроизведением явно включается muted; ручной повтор после ошибки перезагружает видео.

Проверки: Astro check — 0 ошибок/предупреждений. Chromium: 375/800/1440, проигрывание, ручная пауза, пауза вне экрана, контактная кнопка, axe без serious/critical; reduced motion; принудительный запрет autoplay; недоступный MP4; отключённый JavaScript. Во всех аварийных сценариях доступна обложка с домена сайта.

Ограничение: ошибка на конкретном физическом телефоне не воспроизведена, сведения о модели/браузере запрошены. Формат оригинала — H.264 yuv420p, 720×1280, 24 fps; перекодирование не требуется по имеющимся данным.

Выпуск: опубликовано на https://peri.zumrudin.ru, релиз /srv/peri/releases/2026-09-22-gift-video-fallback. Изменённые исходники синхронизированы в /srv/peri/site; резервные копии и предыдущий target симлинка — /srv/peri/backups/2026-09-22-gift-video-fallback. Полный браузерный сценарий повторно прошёл на внешнем HTTPS-адресе. Медиа: внешний GET 200, MIME и SHA-256 совпадают со сборкой; MP4 поддерживает Range 206. SEO: те же 6 прежних ошибок, новых нет. Production на отдельном сервере не обновлялся; адрес проблемной страницы пользователем пока не уточнён.
