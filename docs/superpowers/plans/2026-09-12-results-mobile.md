# Реализация мобильной ленты результатов

1. Создать отдельную ветку/worktree от текущего состояния проекта; собрать исходную версию для сравнения.
2. Добавить мобильные источники в `picture`, сохранив прежний десктопный `Image`.
3. Изменить мобильные стили: карточка 84vw, шаг 14px, фото целиком в рамке 4:5, до 10 карточек.
4. Добавить мобильную навигацию с синхронизацией по прокрутке и изменению ширины, клавиатурой и reduced motion.
5. Проверить сборку, типы, существующие тесты и браузерные сценарии.
6. Снять скриншоты 320/375/390/430/800 px, сравнить десктоп 801/1024/1440 px с исходной сборкой. Проверить 10 и 11 записей через тестовую подмену HTML без записи в CMS.

Проверка браузером: `node scripts/qa/results-mobile.mjs <preview-url> <baseline-url>`. Второй URL необязателен. Скриншоты и отчёт сохраняются в `docs/qa/results-mobile/`.
