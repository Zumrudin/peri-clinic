# Видео услуг: реализация и проверка

- Добавить в декларативную схему `procedure_videos`, связь с услугой и поля
  редактирования. Применить отдельную идемпотентную миграцию на стенде и проде.
- Получать карточки через Content Layer, выбирать только опубликованные,
  сортировать и преобразовывать общим адаптером видео. Включить файлы услуг
  в источники MP4/HLS. Убрать общую подборку главной из TreatmentPage.
- Проверить Astro, сборку, изоляцию двух услуг, исключение черновиков, отсутствие
  блока у пустых услуг, существование MP4/HLS. Удалить тестовые карточки стенда.
- Выпустить изменения обычной сборкой, проверить живой сайт и поля рабочей CMS.

Использование: «Контент → Процедуры → нужная услуга → Видео об услуге → Создать».
В карточке указать подпись, загрузить или выбрать файл в поле «Видео», при желании
добавить обложку, выбрать «Опубликовано». Сохранить карточку и услугу.
Порядок меняется перетаскиванием. Удаление карточки из подборки не удаляет видеофайл.
