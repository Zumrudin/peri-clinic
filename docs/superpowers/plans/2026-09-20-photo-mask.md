# Внедрение редактора плашек

1. Bundle directus/extensions/peri-photo-mask: интерфейс Vue + endpoint Sharp + общая SVG-геометрия.
2. Собрать: Node 22, npm ci --include=dev, npm test, npm run build внутри каталога расширения.
3. Установить package.json, dist и production dependencies в extensions/directus-extension-peri-photo-mask на сервере Directus. Перезапустить только peri-directus.
4. Выполнить directus/setup/photo-mask-schema.mjs с административными реквизитами нужного окружения. Миграция добавляет скрытое поле параметров файла и меняет интерфейсы одиночных фото; содержимое записей не меняет. Повторный запуск безопасен.
5. Проверить disposable CMS и scripts/qa/photo-mask.mjs: неавторизованный запрос, ориентация EXIF, неизменный оригинал, отдельная копия, повторное редактирование, некорректные параметры, браузер desktop/mobile.
6. На рабочей CMS проверить загрузку расширения и схему. Фото пациентов при проверке не изменять.

Откат: сменить интерфейс peri-photo-mask на file-image у полей, удалить каталог расширения и перезапустить peri-directus. Созданные копии остаются обычными PNG и продолжают работать на сайте. Поле peri_eye_edit можно оставить: оно не влияет на вывод сайта.
