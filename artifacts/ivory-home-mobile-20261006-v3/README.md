# Мобильный ребрендинг v3

Продолжение v2: сохранена исходная форма мобильных блоков и новая фирменная палитра.

По правкам владельца:
- На телефоне скрыты большая кнопка «Записаться на консультацию» в hero и фраза «Обсудим ваши пожелания на консультации». Постоянная нижняя панель записи сохранена.
- Три показателя (направления, сертифицированные препараты, время работы) размещены поверх фотографии, строго по нижнему краю, с молочным градиентом и компактной типографикой. Ссылка на результаты остаётся под фото.
- Фон с лепестками масштабируется целиком по ширине телефона. Ранее `background-size:auto 100%` обрезал боковые лепестки. Вуаль секций облегчена; плотные заливки карточек услуг, аппаратов, отзывов и записи заменены полупрозрачными. Фотографии остаются непрозрачными.

Десктопный концепт v4 не изменён: новые правила работают до 800 px.

Сборка и проверка из корня проекта:

```sh
node artifacts/ivory-home-mobile-20261006-v3/build.mjs
node artifacts/ivory-home-mobile-20261006-v3/qa.mjs
```

Проверки: 320, 375, 390, 430, 600, 800 и 1440 px; нет горизонтального переполнения, битых изображений и ошибок загрузки. Проверены меню, запись через нижнюю панель и фотогалерея. На мобильных размерах проверены скрытие кнопки/текста, совпадение нижнего края показателей с фотографией и покрытие фоном всей высоты страницы. Axe на 390 px: 0 serious/critical. Подробности — `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v3/index.html

Основной сайт и CMS не изменялись. Предыдущие версии сохранены. `site/` воспроизводится сборкой из снимка десктопного v4.
