# Мобильный ребрендинг v6: показатели под фотографией

Продолжение v5. По новому референсу владельца показатели направлений, препаратов и времени работы перенесены из наложения на фото в отдельную светлую полосу непосредственно под ним. Три колонки центрированы, добавлены тонкие вертикальные разделители. Градиент поверх нижней части фотографии удалён; текст показателей сохранён.

Остальные правки v5 сохранены, включая удаление адресной строки, декоративной ленты и действий hero. Десктопная компоновка показателей не изменена.

```sh
node artifacts/ivory-home-mobile-20261006-v6/build.mjs
node artifacts/ivory-home-mobile-20261006-v6/qa.mjs
```

QA проверяет размеры 320, 375, 390, 430, 600, 800 и 1440 px, совпадение верхнего края полосы показателей с нижним краем фото на мобильном, скрытые элементы, отсутствие горизонтального переполнения, загрузку изображений, меню, запись и фотогалерею. Axe на 390 px; результаты в `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v6/index.html

Основной сайт и CMS не изменялись. Предыдущие версии сохранены; `site/` воспроизводится сборкой.
