# Мобильный ребрендинг v4

Продолжение мобильного v3. По правке владельца на экранах до 800 px полностью скрыт ряд действий hero, включая ссылку «Смотреть результаты». Показатели остаются поверх фотографии у её нижнего края: нижний отступ уменьшен с 18 до 7 px, боковой — с 20 до 16 px. Молочная подложка под текстом теперь непрозрачная (#f8f5ef), с плавным переходом к фото сверху.

Остальные мобильные блоки и десктопный концепт сохранены.

```sh
node artifacts/ivory-home-mobile-20261006-v4/build.mjs
node artifacts/ivory-home-mobile-20261006-v4/qa.mjs
```

Проверки: 320, 375, 390, 430, 600, 800 и 1440 px; переполнение, загрузка изображений, скрытие действий/вводного текста, привязка показателей к нижнему краю фото, покрытие страницы текстурой, запись через нижнюю панель, меню, фотогалерея и axe на 390 px. Подробности — `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v4/index.html

Основной сайт и CMS не изменялись. Предыдущие версии сохранены; `site/` воспроизводится из сохранённого десктопного v4.
