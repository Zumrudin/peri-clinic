# Финальная десктопная версия ребрендинга — 6 октября 2026

Утверждённая главная страница: https://dev.zumrudin.ru/peri-concepts/ivory-home-20261006-v4/index.html?v=final-badge

`site/` — точный снимок опубликованной версии v4 со стилями, логотипами, шрифтами, изображениями, видео и скриптами. `originals/` содержит оригинал финальной фотографии с бейджем; на странице используются облегчённые WebP 1920 и 3200 px. `final-manifest.json` фиксирует размеры и SHA-256 всех файлов снимка и оригинала.

Первый блок при ширине от 801 px занимает высоту окна минус 68 px меню. Фотография показывается целиком через object-fit: contain; свободная площадь заполнена светлым фоном. Текст и отступы адаптируются к размеру окна. Меню постоянно закреплено сверху без анимации появления. До 800 px текст и фото расположены последовательно; мобильный блок может требовать прокрутки.

Проверены окна 2560×1440, 1920×1080, 1440×900, 1366×768, 1280×720, 1024×768, 820×1180 и 390×844: фото загружается, горизонтальной прокрутки нет; на десктопе блок и текст помещаются по высоте окна. Для HTML и новых WebP проверены внешний GET, HTTP 200, Content-Type и SHA-256.

Это сохранение утверждённой концепции, а не перенос ребрендинга в Astro/Directus или публикация на основном домене клиники. Снимок содержит абсолютные пути `/peri-concepts/ivory-home-20261006-v4/`; для восстановления следует копировать содержимое `site/` в одноимённый каталог `/var/www/peri-concepts/`. Для переноса на другой адрес нужно обновить пути. Родительские build.mjs и QA-файлы относятся к предыдущей итерации и не являются сборкой этого финального снимка.
