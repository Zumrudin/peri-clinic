# Мобильная адаптация ребрендинга v4

Основа: утверждённый снимок `artifacts/ivory-home-20261006-v4/site/` из коммита `1dc21e4`. Палитра Ivory / Taupe / Brass / Dark Taupe, оригинальные логотипы, шрифты и общий ботанический фон сохранены. Изменения ограничены шириной до 800 px.

Все блоки главной адаптированы: шапка и раскрытое меню, hero, направления, клиника и специалисты, аппараты, результаты, отзывы, сертификат, запись и контакты. Услуги на телефоне идут в одну колонку; интерактивные галереи и способы связи унаследованы из v4. Нижняя панель записи и уведомление cookie разведены по высоте с учётом safe area.

Главная фотография не перегенерирована и не изменена. CSS `object-fit: cover; object-position: 80% center` помещает исходник в рамку 4:5 на телефоне (1:1 на планшете). Сохраняются врач, клиентка, настенная монограмма и букет; убрана пустая стена слева. Для такого блока отдельная генерация не нужна. Для фото на весь экран 9:16 с текстом поверх потребовалась бы другая композиция.

Воспроизведение из корня репозитория:

```sh
node artifacts/ivory-home-mobile-20261006/build.mjs
node artifacts/ivory-home-mobile-20261006/qa.mjs
```

`build.mjs` копирует полный снимок v4, меняет только префиксы путей и добавляет `mobile.css` последним. Поэтому у страницы нет зависимости от опубликованного каталога v4. Сгенерированная копия `site/` не дублируется в git; её можно восстановить командами выше.

Проверены ширины 320, 375, 390, 430, 600, 800 и 1440 px, отсутствие переполнения и битых изображений, открытие записи, меню и фотогалереи. Axe на 390 px: 0 serious/critical. Результаты — `qa.json`.

Просмотр: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006/index.html

Это мобильная адаптация сохранённого концепта главной. Рабочий Astro-сайт, Directus и основной домен клиники не обновлялись. Переходы на внутренние страницы ведут на существующий сайт, как в исходном v4.
