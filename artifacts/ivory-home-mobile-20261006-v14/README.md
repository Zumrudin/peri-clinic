# Мобильный ребрендинг v14: ссылки на сотрудников и центрирование аппаратов

Продолжение v13:
- У фотографий сотрудников удалены плюсики и атрибуты открытия фотогалереи. Фото ведёт на тот же URL страницы сотрудника, что и «Подробнее», с соответствующим aria-label.
- На мобильном у «Подробнее» убран автоматический верхний отступ; ссылка следует сразу за описанием с интервалом 4 px до области ссылки.
- Названия, описания и «Подробнее» в карточках аппаратов выровнены по центру.

```sh
node artifacts/ivory-home-mobile-20261006-v14/build.mjs
node artifacts/ivory-home-mobile-20261006-v14/qa.mjs
```

QA: 320, 375, 390, 430, 600, 800 и 1440 px; адреса ссылок сотрудников, отсутствие плюсиков и lightbox-атрибутов, расстояние до «Подробнее», центрирование аппаратов, общие проверки. На 390 px проверен реальный клик по фото с перехватом только страницы назначения. Результаты — `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v14/index.html

Сборка адаптирует сохранённый JS галереи: карусель использует все `.gallery-photo`, а lightbox привязывается только к оставшимся `[data-photo]` (интерьеры).

Основной сайт и CMS не изменялись. Предыдущие версии сохранены; `site/` воспроизводится сборкой.
