# Мобильный ребрендинг v11: индикатор прокрутки «Жизнь клиники»

Под видеокарточками добавлена навигация по образцу блока результатов: полоса прогресса, текущий номер/общее количество и стрелки. Разметка и scoped-стили скопированы из навигации результатов при сборке. Отдельный `reels-scroll.js` синхронизирует полосу с фактической прокруткой; стрелки вызывают существующий контроллер видео через его кнопки выбора, сохраняя управление воспроизведением. Старые точки скрыты на мобильных, подсказка остаётся.

Индикатор плавно соответствует доле прокрученной ленты, начиная с 1/N и заканчивая полной полосой. Учтены изменение ширины и первый/последний ролик. Существующее управление лентой с клавиатуры сохранено.

```sh
node artifacts/ivory-home-mobile-20261006-v11/build.mjs
node artifacts/ivory-home-mobile-20261006-v11/qa.mjs
```

QA на 320, 375, 390, 430, 600, 800 и 1440 px. На мобильных дополнительно проверяются переход ко второму видео, возврат к первому, прокрутка до последнего (полный прогресс, отключённая стрелка), возврат клавишей Home. Сохранены проверки компоновки, изображений, меню, записи, фотогалереи и axe. Результаты — `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v11/index.html

Основной сайт и CMS не изменялись. Предыдущие версии сохранены; `site/` воспроизводится сборкой.
