# Мобильный ребрендинг v2: исходная форма блоков и текст поверх фото

Основа — десктопный концепт v4 из `1dc21e4`. По правкам владельца возвращены размеры, сетки и скругления блоков действующей мобильной реализации, сохранённые в базовом CSS снимка. `build.mjs` извлекает исходные геометрические правила через PostCSS, ограничивает их экранами до 800 px и применяет поверх ребрендинга. Палитра, фотографии, логотипы и фирменные шрифты остаются от v4.

В услугах снова широкая первая карточка и две меньшие под ней. Восстановлены исходные формы галерей, аппаратов, результатов, отзывов, сертификата, блока записи и кнопок.

Первый экран: заголовок и вводная строка поверх фото с мягкими градиентами для читаемости. Кнопки находятся в потоке сразу под фотографией; преимущества — ниже. Фотография не изменена: кадрирование выполняет CSS. Настенный логотип, букет, врач и клиентка остаются видимыми. Десктоп не менялся.

```sh
node artifacts/ivory-home-mobile-20261006-v2/build.mjs
node artifacts/ivory-home-mobile-20261006-v2/qa.mjs
```

Проверены 320, 375, 390, 430, 600, 800 и 1440 px, загрузка изображений, ширина документа, запись, меню и фотогалерея. На 390 px axe: 0 serious/critical. Отчёт — `qa.json`. Сгенерированный `site/` воспроизводится из сохранённого v4 и не дублируется в git.

Публикация концепта: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v2/index.html

Основной сайт и Directus не изменены. Предыдущая мобильная версия сохранена отдельно.
