# Мобильная v16: спокойная прокрутка сотрудников

Основана на мобильной v14 (`68b7b69`), восстановленной откатом `e3c2821`. Фотографии направлений остаются прежними.

В мобильной галерее сотрудников (до 800 px) один жест ограничен соседней карточкой. Перемещение непосредственно за пальцем ограничено одним шагом; скорость отпускания даёт лишь небольшой доводящий импульс выбора цели, а не многошаговую инерцию. Порог выбора — 22% шага; добавка от скорости ограничена 15%. Остановка использует существующую критически затухающую пружину response 0.4 / damping 1 с нулевой стартовой скоростью, без перелёта. Движение можно прервать новым жестом. При reduced motion фиксация мгновенная.

Отдельный модуль `staff-carousel.ts` адаптирует карусель снимка. Ограничение действует только внутри `.portraits` при мобильной ширине. Навигация стрелками, десктоп и галерея интерьеров сохраняют существующее поведение. Продакшен-исходники и CMS не менялись.

```sh
node artifacts/ivory-home-mobile-20261007-v16/build.mjs
node artifacts/ivory-home-mobile-20261007-v16/qa.mjs
```

QA использует реальные touchStart/touchMove/touchEnd через Chrome DevTools Protocol: 375, 390, 430, 800 px, дополнительно reduced motion на 390 px. На каждом размере проверены пять быстрых свайпов в обе стороны, короткий жест, возврат transform к нулю, вертикальная прокрутка и переход по фото в профиль. Ленивая загрузка видео из исходного снимка изолирована в тесте: в нём ранее отсутствовали hls.light.DGbT2ul9.js и reel-streams.BpewDxZ1.js. Эти старые проблемы видео не входят в данное исправление.

Публикация: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261007-v16/index.html#approach-team

Изменённые опубликованные HTML/JS проверены внешним GET, Content-Type и SHA-256; отчёт `delivery-verification.json`. Реальное ощущение жестов желательно дополнительно оценить на телефоне пользователя.
