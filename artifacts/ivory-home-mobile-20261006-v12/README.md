# Мобильный ребрендинг v12: прозрачный фон специалистов и аппаратов

Вариант для просмотра на новом ботаническом фоне. Все 4 исходных портрета специалистов и 8 изображений аппаратов уже содержат альфа-канал (проверены метаданные и диапазон alpha 0–255). Редактирование или генерация изображений не требовались.

На мобильных экранах убраны CSS-заливки карточек/контейнеров фотографий специалистов и аппаратов. Сквозь прозрачные участки оригинальных WebP виден общий фон страницы с молочной вуалью. Сами фотографии, лица, детали оборудования и их размеры не изменены.

```sh
node artifacts/ivory-home-mobile-20261006-v12/build.mjs
node artifacts/ivory-home-mobile-20261006-v12/qa.mjs
```

QA на 320, 375, 390, 430, 600, 800 и 1440 px, включая проверку прозрачного computed background карточек/контейнеров, компоновки, галерей, видеонавигации и axe. Результаты — `qa.json`.

Концепт: https://dev.zumrudin.ru/peri-concepts/ivory-home-mobile-20261006-v12/index.html

Основной сайт и CMS не изменялись. Предыдущие версии сохранены; `site/` воспроизводится сборкой.
