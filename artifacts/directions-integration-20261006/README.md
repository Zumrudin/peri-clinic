# Направления: мобильная v15 и десктопная v5

Основания: мобильная v14 — `68b7b69`, финальный десктопный ребрендинг v4 — `1dc21e4` (6 октября 2026). Изменён только блок `#services`; ссылки категорий сохранены. Мобильный вариант: аппаратная карточка во всю ширину с фото справа, ниже две карточки. Десктоп: три карточки в ряд, заголовок и пояснение в двух колонках. Сохраняются шрифты и ботанический фон соответствующего концепта.

Выбранные пользователем оригиналы находятся в `originals/`: аппаратная и эстетическая — светлая генерация с атласным халатом и горизонтальным логотипом на повязке; губы — первая светлая генерация. Фото используются отдельно от растрового референса. WebP кодируется без потерь и без изменения разрешения: 1122×1402, 1448×1086, 1448×1086. Текст и ссылки остаются HTML.

Воспроизведение из корня проекта:

```sh
node artifacts/directions-integration-20261006/build.mjs
node artifacts/directions-integration-20261006/qa.mjs
```

Проверены мобильные размеры 320, 375, 390, 430, 600, 800 и 1440 px; десктопный концепт — 390, 820, 1024, 1440 и 1920 px. Проверены загрузка фото полного разрешения, отсутствие переполнения текста и горизонтальной прокрутки, расположение карточек, ссылки, работа контактного окна и сохранение ссылок специалистов в мобильной версии. Axe: нет serious/critical в новом блоке. Снимки браузера: `mobile-directions.png`, `desktop-directions.png`; результаты: `qa.json`.
